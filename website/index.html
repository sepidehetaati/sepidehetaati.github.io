Data Collection and Algorithm Development for Human Attention Assessment

Master's Thesis 2024

Designed and implemented a comprehensive system to evaluate human attention based on movement patterns. Developed a computer-based version of the Trail Making Test (TMT) and recorded participants' behavioral data, including eye gaze tracking and mouse trajectories. Extracted features such as fixations, saccades, blinks, and cursor behavior, then used machine learning regression models to predict attention and mindfulness scores. Development of a Lower Limb Gait Asymmetry Index with Cyclogram Analysis Using Image Processing

asymmetry 2024

In this project, we developed a gait asymmetry index using image processing techniques applied to cyclogram analysis. The goal was to evaluate changes in lower limb symmetry under different walking conditions, such as wearing a knee brace or carrying a weight.
We collected joint angle data (hip, knee, ankle) using IMUs and analyzed it through a new asymmetry index that integrates cyclogram area, trend symmetry, and shape length. This method effectively captured variations in gait and identified asymmetries, particularly in the hip joint.
The proposed index was statistically validated and demonstrated strong potential for clinical gait assessment and robotic locomotion design, providing valuable insights for rehabilitation, biomechanics, and bipedal robot development.

    We developed a custom Asymmetry Index to quantify gait symmetry based on cyclogram analysis. This index combines three key parameters:
  • Area of the angle-angle cyclogram diagram
  • Trend Symmetry between joint angles
  • Longest Lengthacross the cyclogram shape, measured by intersecting a fitted line with the shape boundary
    • Asymmetry Index = (Area × Trend Symmetry) / Length
    A smaller index value indicates a more symmetric gait pattern, making it a useful tool for evaluating walking conditions and identifying asymmetries.

RSNA Screening Mammography Breast Cancer Detection

Breast cancer detection project 2023

This project focused on classifying breast cancer cases using mammography images from the RSNA Screening Mammography dataset. Due to the significant class imbalance, duplicate non-cancer samples were removed to improve balance, and data augmentation was applied to enhance model generalization.
Several CNN architectures, including VGG16, VGG19, and ResNet50v2, were evaluated. In the final phase, EfficientNetV2 was trained using advanced techniques, including learning rate scheduling, weighted binary loss, binary focal loss, and AUC-ROC evaluation. Additional methods, such as label smoothing and weighted random sampling, were employed to address the imbalance and reduce overfitting.
The results showed that combining transfer learning with targeted preprocessing and training strategies can improve classification performance on challenging medical datasets.

Advanced Control and Optimization of a Cable-Driven Parallel Robot

Cabel robot project 2023

This project focused on controlling a cable-driven parallel robot (CDPR) using various control strategies and optimization methods. Three controllers were implemented and tested: a classical PID controller, a fuzzy logic controller, and a hybrid fuzzy-PID controller. Among them, the fuzzy-PID controller demonstrated better performance in terms of stability and responsiveness.
To reduce the impact of noise and disturbances, a low-pass filter was applied to the PID controller, resulting in improved control behavior. Furthermore, the system was optimized using ANFIS, genetic algorithms (GA), and particle swarm optimization (PSO). ANFIS provided the most effective performance enhancement, while GA showed moderate improvement, and PSO had minimal effect

Steel Surface Defect Detection and Segmentation Using Deep Neural Networks

Steel defect detection project 2024

Developed a deep learning-based system for automatic detection of surface defects in steel sheets, addressing a critical challenge in the manufacturing industry. This project explored multiple computer vision approaches, including semantic segmentation and object detection, to improve detection accuracy—especially for small defects.
We implemented several segmentation models (U-Net, FCN-8, and FPN) as well as an object detection model (YOLOv4). Building upon the two-stage approach previously used in our wheat disease detection project, we combined object detection and segmentation into a unified pipeline. This hybrid method improved performance, achieving a Dice Similarity Coefficient of 84% in detecting small surface defects.
The U-Net model with pre-trained backbones reached the highest segmentation accuracy (Dice Score: 72%), while YOLOv4 achieved a mean Average Precision of 49.32% for binary class detection and 35.06% for multi-class detection. These results validate the effectiveness of the proposed two-stage method for industrial surface inspection tasks.

Intelligent Inspection of Agricultural Crops with Computer Vision

Bachelor's Thesis 2022

Designed and implemented an intelligent system to diagnose wheat diseases using image processing and a mobile robot. The project integrated two key components: autonomous navigation and wheat disease detection.

  • Autonomous Navigation: A TurtleBot3 robot was controlled within the ROS and Gazebo simulation environments. Using SLAM for mapping and localization, and a PID controller for path planning, the robot successfully navigated toward target positions in a structured environment.
  • Disease Detection: We developed a two-stage deep learning pipeline. First, a YOLOv4 object detection model was used to locate wheat regions in images. Then, a VGG19 classification model identified specific disease types affecting the crops in cropped images from YOLO4. We trained the system using two wheat disease datasets to improve robustness and accuracy.
